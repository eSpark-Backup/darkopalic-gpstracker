# darkopalic-gpstracker
 The product is expected to be used in car parking areas where the users will put trackers on their cars enabling client to determine if the car is inside the parking space or not.

## Product Application
The product is intended to be used for car tracking purposes. It requires very precise GPS positioning that is accurate up to **40cm**. The product will be used for car parking spaces geo fencing where the end user can determine available parking spaces (occupied or vacant) and the admin can also monitor the traffic / activity on the parking spaces.
